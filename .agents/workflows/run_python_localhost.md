# Запуск локального сервера Python

Этот скилл (workflow) позволяет быстро поднять локальный HTTP-сервер на Python для тестирования и просмотра статических файлов (HTML, CSS, JS).

// turbo

1. Запустите встроенный сервер Python в корне проекта на порту 8000:
   `python -m http.server 8000`

2. Теперь вы можете открыть сайт в браузере по адресу: [http://localhost:8000](http://localhost:8000)
